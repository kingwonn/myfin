# 事件风险层规格 v1.0（黑天鹅状态机）——奖励函数的"刹车系统"

依据：主线 docs/research/2026-07-11-m1-blackswan.md（M1）+ M1b 冲击端参数补证（104 代理，19 条主张过 3 票对抗验证）。参数一律标注 [实证] 或 [推断] 与验证票数。

## 小白版：这是什么

给交易算法装的自动刹车：平时不管事；探测到"危险信号"（川普关税言论/重大政策头条/议息日临近）就自动踩下不同深度的刹车（减仓/停手），危险解除自动松开。v1.0 的升级：刹车的力度和时长，现在有了 2025 年"解放日"关税冲击的实测数字做标定。

## 状态机（三态）

```
NEUTRAL(中性) ←→ ELEVATED(升波预警) ←→ SHOCK(冲击中)
```

## TACO 子模块（E2/E4 的撤回端）

> TACO = "Trump Always Chickens Out"，FT 专栏作家 Robert Armstrong 2025-05-02 命名 [实证 3-0]。指"威胁→暴跌→约一周软化→反弹"模式。

- 案例库 [实证]：NBC 10 个完整"威胁→后撤"案例（欧盟/加墨/中国/iPhone/汽车等）；Forbes 追踪器至 2025-07-14 累计 **≥28 次**关税变卦（2-1）。
- 三种子类型：**完全撤回 / 延期 / 降级**（欧盟 20%→威胁 50%→延后 7/9 属"降级为延期"）——回测标注须区分。
- 单日兑现上限样本：+9.52%（4/9）。
- ⚠️ **未闭合缺口**：28 次变卦的系统性"买威胁跌"盈亏回测未量化；威胁被**兑现**的反例（对华一度 145% 的窗口）盈亏未量化。→ TACO 方向暂只做**减仓节奏参考**（跌时不恐慌清仓），不做主动抄底信号。

## 尾部对冲接力设计（E6 的 30 日分叉）

[推断-模型结论，3-0 ×2，三个独立来源一致]：期权凸性保险在**跳跃冲击瞬间**生效（适配 TACO 类 V 型急跌）；趋势跟踪对第一次冲击必然滞后但在**持续回撤**中防御递增、无期权金消耗（适配慢熊）。两者按时间维度互补：

```
冲击发生 ──0-30日──> TACO情景: V型反弹, 期权凸性/持币观望覆盖
          └─30日未解除──> 非TACO尾部: 趋势跟踪接力 + 人工评审
```

量化参考（[实证-回测，样本内]，IAJ 2025 同业评审，2-1/3-0）：ACWI + 10-delta put 尾保 + 50% 趋势跟踪叠加：CAGR 8.06%→11.02%、波动 15.57%→13.23%、Sharpe 0.37→0.66、最差 3 个月滚动收益 -34.3%→-19.1%（注意是滚动季度口径，非最大回撤）、月度 alpha +0.25% 显著。超额集中于互联网泡沫与 2008 两段，对期权成本假设敏感——**只作方向证据，不作收益预期**。

- ⚠️ Universa 实绩口径之辨**全部未过验证**：凸性对冲成本参数（年化 bps 拖累）缺口仍开放，缺口期取保守值（假设成本上限=IAJ 回测隐含净成本）。
- 对我们的落地（无衍生品纪律下）：期权凸性我们不做，等价物 = **现金比例**（SHOCK 态强制现金≥50%即是我们的"凸性"）；趋势跟踪接力 = 30 日未解除后按 risk-rules 回撤阶梯纪律性降敞口。
