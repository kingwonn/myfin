# 奖励函数 v1.0 总设计（SOTA 拼装 + 我们的纪律）

## 小白版：这是给交易算法定的"考试评分标准"

四条打分规则，训练出一只**稳健而不是莽撞**的算法：
1. **赚钱加分——但按风险打折**：在颠簸股票上赚的钱，得分打折（防止算法去赌过山车）
2. **亏钱重罚——亏得越深罚得越狠**：回撤惩罚是凸的（亏 10% 的罚分远超亏 5% 的两倍）
3. **每笔交易先交"过路费"**：按真实成本模型扣分（含"买多了自己推高价格"的冲击成本），治好频繁交易多动症
4. **危险时刻逞英雄=直接大负分**：黑天鹅状态机亮黄灯/红灯时还加仓，一票重罚

## 形式定义

```
R_t = w_r·f(r_vol) − w_d·g(DD_t) − w_c·Cost_t − λ_e·EventPenalty_t + HardRules
```

| 项 | 定义 | SOTA 来源（验证票数） |
|----|------|---------------------|
| f(r_vol) | 多周期前向收益(3/7/15日,权重0.3/0.5/0.2) ÷ 20期滚动波动率，**非对称映射**（负端更陡） | Trading-R1 (3-0) + M1不对称实证 |
| g(DD) | 凸回撤惩罚：g = (DD/DD_max)²·κ；触及风控阶梯(-10/-15/-20%)分档跳升，-20%回合终止+大负分 | RA-DRL 融合思路 + docs/risk-rules §5 |
| Cost | 固定费+点差下限+平方根冲击项 σ·√(x/V)（小资金也保守计入） | MACE/Almgren-Chriss (3-0) |
| EventPenalty | 状态机乘子：NEUTRAL=0；ELEVATED/SHOCK 中持有超限敞口按超出比例罚分 | event-risk-layer.md (M1 实证) |
| HardRules | ①黄/红灯加仓→大负分；②杠杆动作不存在于动作空间（多头单纯形+现金，GIFT 式）；③换手率超帽→罚分 | 我们的铁律 |

## 反"钻空子"(reward hacking)设计

- 各分量有界（clip），防单项刷分
- 动作空间物理排除杠杆与做空——不是罚，是**做不到**
- 波动率归一化使"躲进低波动刷微利"与"赌高波动搏大赢"同样无利可图

## 治理（凌驾于训练之上）

1. 权重 (w_r,w_d,w_c,λ_e) 单纯形网格搜索——**每一组都计入试验次数 N**，最终报 DSR（回测协议 v1.1）
2. 验证一律 CPCV；Walk-Forward 不得单独使用
3. **全领域零实盘证据的现实**（Q-SOTA 3 票确认）→ 本奖励函数只用于纸面前向实验评分；通过 Q1-Q3 阶段门前不碰真钱
4. 事件层参数缺口（M1b 补证中）期间取保守值

## v1.2 修订队列（红队 2026-07-12 驱动，按治理顺序执行）

> 顺序铁律：①先在本节定稿规格修订 → ②独立代理更新裁判套件（红队场景固化为回归不变量）→ ③再改实现。跳过任何一步=运动员兼裁判复辟。

1. **H1 波动率同期化**：f(r_vol) 的归一化分母改为与前向收益同窗口的已实现波动率（现为滞后 20 期，同收益可套 4 倍分，奖励"平静期埋伏"）。
2. **H2 持有超帽累罚**：event 惩罚随停留在超帽状态的步数递增（现只罚加仓瞬间，score>1.333 时硬扛净正、反罚合规减仓者）。
3. **H3 成分风险项**：事件层加持仓加权波动率或 HHI 集中度罚分（现 SHOCK 帽内全押最热名零罚且多得 +0.72/步）；与 E3 个股帽合并实现。
4. **H5 终止惩罚单调化**：DD_TERMINAL_PENALTY 调整为 ≤ 任何非终止步最坏值（现 dd=0.19 比跌穿 0.20 更痛 3.83 分，教算法"跌穿止损封顶损失"）。
5. **H4/H6 引擎化**：以 RewardEngine 类持有 book 计价单位与回合级高水位，消灭"自报口径"面（v1.1 已加 prior_peak 与单位契约文档作过渡）。
6. **G-3 前向窗口去重**：RL 训练版对相邻步重叠的前向收益去重/折扣。
