# 00 · 愿景与策略框架

## 一、我们在做什么

三句话：

1. **目标**：搭上 AI 算力中心产业链与 Physical AI 产业链的发展轨道，在二级市场获得高倍收益。
2. **手段**：构建"言出法随"AI-native 投研系统，让研究的深度、频率、纪律性远超个人手工所能达到的水平。
3. **路径**：找到窄门——不是买人人都在买的东西，而是找到**高确定性 × 高弹性 × 低拥挤度**的交集。

## 二、为什么现在

- AI 资本开支进入以"电力、封装、光互连、机器人"为瓶颈的深水区，**瓶颈即咽喉，咽喉即定价权**。
- 产业链信息高度分散（美股/A股/港股/日韩、上市/未上市、财报/供应链调研/技术路线之争），**个人手工跟踪已经跟不动了**——这正是 AI-native 系统的用武之地。
- Agent 技术（Claude Code 及其生态）已经成熟到可以把"研究流程"本身工程化。

## 三、"窄门"的操作性定义

一个标的/环节要进入窄门候选清单，必须同时满足：

| 维度 | 判据 | 反例 |
|------|------|------|
| 高确定性 | 处于产业链**绕不开**的位置：技术代差、产能独占、生态锁定、认证壁垒，至少占其一 | 纯故事、可被绕开的中间商 |
| 高弹性 | 收入/利润对 AI 需求的敏感度高，且市值尚未完全 price in | 已经是十万亿市值、边际弹性衰减的巨头 |
| 低拥挤度 | 尚未成为共识核心持仓；或共识存在认知偏差（低估了持续时间/幅度） | 全网都在喊的标的 |

三者交集极小——所以叫窄门。宁缺毋滥。

## 四、两条产业链的跟踪框架

### 4.1 AI 算力中心产业链（Compute Chain）

按物理层次分环节，每个环节问三个问题：**谁绕不开？产能弹性多大？替代路线是什么？**

```
芯片层：GPU / 自研ASIC / HBM / 先进封装(CoWoS等)
互连层：Scale-up(NVLink等) / Scale-out(IB vs 以太网) / 光模块 / CPO / 硅光
供电散热层：液冷 / 电源(UPS·HVDC) / 变压器 / 燃气轮机 / 核电SMR
土地与运营层：数据中心REIT / Neocloud(GPU云) / 电力供应商
```

### 4.2 Physical AI 产业链

```
大脑层：机器人 foundation model / 仿真训练(Isaac·GR00T等) / 芯片(Thor等)
本体层：人形整机 / 四足 / 工业形态
关节层：执行器 / 谐波减速器 / 行星滚柱丝杠 / 空心杯电机
感知层：激光雷达 / 视觉 / 触觉·力控传感器
```

### 4.3 未上市咽喉公司

不能直接买 ≠ 不用跟踪。跟踪它们的意义：

1. 它们的技术路线选择决定上游供应商的命运（间接选股信号）;
2. 上市前后往往是产业链重估的催化剂;
3. 存在间接敞口渠道（持股方上市公司、封闭式基金类工具等)。

## 五、纪律

1. 论点先行：没有写成文字、通过证伪检查的论点，不产生任何仓位建议。
2. 触发式行动：每个论点必须定义"加码触发器"和"退出触发器"。
3. 定期复盘：错误分析写进 journal，错误模式沉淀回系统规则（CLAUDE.md / 技能）。
4. 系统建设本身也走"窄门"：只建对研究质量有杠杆的功能，不堆砌。
