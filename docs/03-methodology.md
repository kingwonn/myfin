| `funding_source` + `substitute_maturity` | Gavin Baker "follow the money" | 谁在为该环节付钱；替代路线（CPO/FOPLP/降 HBM 用量）距量产几年 |

### 1.2 `theses/TEMPLATE.md` 改造（六处）

1. **第 1 节论点陈述**拆为两个必填子节：「当前价格已计入的共识」+「18-24 个月后的差异化图景」（Druckenmiller）；咽喉类论点加一行 benefit/barrier 双测试（7 Powers）。
2. **第 2 节证据链**强制 claim-evidence 绑定（Trading-R1）：每个 claim 必须挂具体数据点/文件段落，单一来源标 `[未交叉验证]`，产能/订单数字须两个独立来源互证（SemiAnalysis 纪律）。
3. **第 4 节触发器**改为**三通道退出**结构化字段：`exit_falsified`（沿用证伪条件）、`exit_momentum`（具体价格/结构位）、`exit_valuation`（价格隐含预期超出自身牛市情形或拥挤度极端）。任一触发即执行，不许用另两条"还好"否决；豁免须写入 journal 且不可事后修改（针对 JF 2023"卖出是实证最弱环节"）。
4. **第 5 节后新增 5.5 仓位建议**：主观概率×赔率算 raw Kelly ×0.25~0.5，叠加单仓硬上限（进攻层 15-20%），决策带波动率语境（同样看多结论在高波动标的上仓位/止损不同），入仓前过"归零测试"。
5. **加码触发**从自由文本改为必填可观测条件清单，对应三档建仓：观察仓 ≤1/3 → 确认仓 ≤2/3（证据+价格双确认）→ 满仓（拥挤度检查通过）。观察仓先触发 exit_momentum 则直接清仓转复审。
6. **第 6 节拥挤度**从建仓时一次性判断改为每季必更新评分，且与仓位档位联动（拥挤度升档→仓位上限自动降档）。

### 1.3 新建文件

- **`docs/risk-rules.md`**：杠铃双层资金结构（生存层永不调入进攻层；利润棘轮回流）；回撤阶梯（进攻层 -10% 冻结新仓 / -15% 无新证据仓位减半 / -20% 强制半仓+2 周冷却复盘）；单桶暴露 ≤ 进攻层 40-50%，AI 叙事总暴露设硬顶；高波动标的（90 日年化波动 >60%）仓位 = 风险预算 ÷ 2-3 倍 ATR 止损距离；分批止盈默认 1 倍兑现 1/3、2 倍再 1/3、余仓移动止损。
- **`docs/research/bottleneck-clock.md`**：轮动时钟正式文档。骨架时间线：2023 CoWoS → 2024 HBM → 2025 电力+光模块 → 2025H2-26 常规存储 → 2026+ 先进制程晶圆 → 2028-30 EUV/ASML；平行瓶颈：燃机（GEV 售罄至 2029）、变压器（交期约 5 年）、技工劳动力、资本/信贷（反向瓶颈，风控项）。规律：瓶颈窗口 = capex 脉冲到达时刻 + 该环节供给时间常数。
- **`docs/research/macro-dashboard.md`（或 /brief 固定段落）**：季度更新五大厂 capex 实际值/指引/**增速二阶导**/债务融资占比；每条链环节标注 Buildout/Boom/Bubble-risk（arXiv 2606.01575 分类法）；三个系统级证伪信号——scaling law 断裂、端侧推理里程碑、hyperscaler ROIC 恶化（Gavin Baker bear case）。

### 1.4 `CLAUDE.md` 新增系统级纪律

- **不为清单**（段永平）：不为看不懂商业模式的标的立论点；不因错过上涨降低入选标准;不用"这次不一样"为已触发的退出触发器辩护；论点被证伪只许标 falsified 不许改写历史；活跃论点数上限 ≤8（逼迫排序而非收集）。
- **前向验证纪律**（DeepFund/AMA 防泄漏范式）：论点验证一律"创建日快照 + 前向跟踪"，**禁止**让模型回看历史行情打分作为证据——LLM 预训练含历史行情，回看式验证必然被记忆污染。
- **利益相关标注**：引用持仓分析师（Baker、Patel 等）观点必须标注利益相关，关键数字第二来源交叉验证。
- **系统性证伪条件（写入所有 active theses）**：≥2 家超大厂下修 capex 指引，或 AI 循环融资/信贷指标（超大厂发债利差、私募信贷违约率）恶化 → 全组合强制复核。

### 1.5 技能改造

- **/thesis**：新建咽喉类论点强制走八问 checklist + 不为清单 gate → bull/bear 两子代理各写论据互相反驳（TradingAgents 结构，移植提示词不移植框架）→ 多风格评审团（价值/逆向/尾部风险三视角，ai-hedge-fund persona 思路）→ 输出强制 claim-evidence 绑定。
- **/scan**：新增事件沿图传播；对每个 active 论点逐条核对三通道退出；标的增加"物理证据"栏（扩产/招工/环评/供应商公告——物理数据领先财报 2-4 个季度，正是低拥挤度窗口）；季度刷新 Epoch 式"AI 需求/环节总产能占用率"（>80% 且上升 = binding constraint）；事件带半衰期属性（FinMem：盘面异动=天级、业绩指引=季级、商业模式变化=年级）。
- **/brief**：输出桶级暴露表 + 当前回撤档位 + 时钟全景图 + "再来一次 DeepSeek 式冲击的单日回撤估计"压力测算。
- **新增 /retro（复盘技能）**：FinCon CVRF 式信念沉淀——每次论点验证结果落地后生成一条可引用的"教训/信念"条目（如"该公司管理层指引历史上系统性乐观"），写入长期记忆，下次评审同类论点时自动注入；同时统计"差点违反不为清单"次数作为纪律健康度指标。

## 三、明确不采纳的方法及理由

| 不采纳项 | 理由 |
|---|---|
| **LangGraph/AutoGen 等 agent 编排框架**（TradingAgents/FinRobot 本体） | 与"git 仓库即系统、Claude Code 即运行时"架构正面冲突；其价值在提示词与流程设计，已按 P2 方式吸收 |
| **自训/微调金融模型**（FinGPT 训练路线、Trading-R1 复现） | GPU 与数据维护成本对个人系统性价比极低；Trading-R1 只抄其输出规范（claim-evidence 绑定+波动率语境） |
| **全市场因子挖掘范式**（RD-Agent 循环、qlib 全家桶进 Phase 1） | 标的池几十个、决策频率周/月，真实需求是假设验证不是因子工厂；框架重、学习成本与收益不匹配 |
| **zipline / backtrader / nautilus_trader** | 前两者停更 2 年（backtrader 还是 GPL）；nautilus 是交易执行引擎，越出 CLAUDE.md"不做真实交易"边界 |
| **ghostfolio 组合跟踪** | 常驻 Web 服务+数据库，与仓库即系统冲突；且其账户-交易模型装不下"持仓挂论点"结构。自建 YAML+脚本，仅借其 TWR 口径作对照 |
| **AutoHedge 及同类营销驱动项目** | 高星≠高质量的对照样本；方法论无增量、评测不严谨。筛选参考实现一律以论文支撑+评测严谨性为准 |
| **主题 ETF 作为暴露载体** | RFS 2023：专门化 ETF 上市后 5 年风险调整亏约 30%——迟到的拥挤载体。反向利用：新发 AI/光模块/机器人主题 ETF 潮列为拥挤度顶部信号源 |
| **回看式历史验证**（让 LLM 对历史行情打分） | 预训练信息泄漏，结论不可信。一律前向验证 |
| **全 Kelly 仓位** | 路径上常见 50-80% 回撤，参数误差下超 2 倍 Kelly 预期增长归零。只用 0.25~0.5 分数 Kelly |
| **尾部期权对冲（现阶段）** | 长期做多凸性侵蚀收益。降为 `docs/research/` 待研项，触发条件：AI 总暴露达上限且拥挤度极端 |
| **美股同市场客户动量套利** | 异象公开后已衰减；只做残留有效区——跨市场（美股客户→A股/亚洲供应商）+中小市值环节 |

## 四、我们的方法论 v1（一页纸草案）

### 命名：窄门四层法——瓶颈选赛道、护城河选公司、证伪管论点、纪律管仓位

**第一层｜瓶颈轮动：在哪里找（赛道层）**
瓶颈不消失、只迁移：按 capex 传导顺序（芯片→光互连→封装/存储→电力→材料/劳动力，各滞后 3-12 个月）依次暴露；供给时间常数越长（光模块 6-12 月 < 封装 12-18 月 < 燃机/变压器 3-5 年 < 晶圆厂 3-4 年 < 劳动力 5-10 年）的环节，瓶颈来得越晚、持续越久。用**八问 checklist** 判定（Q1 需求硬拉动+占用率>80%、Q2 供给刚性、Q3 集中度 CR3>70%、Q4 售罄/涨价打满证据 → 确认；Q5 提价+毛利率扩张 → 兑现；Q6 绕行路径、Q7 资本响应、Q8 拥挤度 → 退出）。只投 **solvers** 不投 causers；瞄准"10% 盈利 / 100% 卡点"的错位环节。仓位重心放"主升+深化"档，用"酝酿期"环节的订单/交期做轮动领先指标。

**第二层｜护城河：买哪一家（公司层）**
五源定性（转换成本/网络效应/无形资产/成本优势/效率规模）+ **持续期重于幅度**（周期性短缺≠护城河）+ benefit/barrier 双测试（卡位真、赚钱假的陪跑者不投）。同环节候选用质量因子（毛利率/ROIC/净负债）剔除靠融资续命者，用相对动量确认市场投票方向。数据用物理证据链自下而上验证：扩产/招工/环评/上游设备订单——物理数据领先财报 2-4 个季度，这就是低拥挤度窗口。

**第三层｜论点证伪:怎么想（认知层）**
每个仓位挂一个论点文件，论点必须写清:①当前价格已计入的共识；②18-24 个月后的差异化图景；③每个 claim 绑定 evidence（双源互证）;④"我错了的情形"——可观测、可检验，写不出=信仰不是论点。验证一律**创建日快照+前向跟踪**，每个论点是一次前向实验。复盘沉淀"信念条目"注入未来同类评审。评审用 bull/bear 对抗+多风格评审团制造冲突证据。活跃论点 ≤8。

**第四层｜仓位纪律：下多大注、何时离场（执行层）**
资金结构杠铃化：生存层（永不投入）/进攻层（按可能整体重挫 50%+ 设预算），利润棘轮回流。单仓 = raw Kelly × 0.25~0.5，硬上限进攻层 15-20%；风险单位是**独立论点数**不是标的数——整条 AI 链是同一叙事因子（DeepSeek 日为证），单桶 ≤40-50%。建仓三档金字塔：观察仓 1/3 → 双确认后 2/3 → 满仓；走反直接清。退出三通道（证伪/破位/兑现）任一触发即执行，豁免须书面记录。回撤阶梯机械执行：-10% 冻结 / -15% 减半 / -20% 半仓+冷却。拥挤度是持续的退出输入：自己的"低拥挤"标的变成共识核心仓、被新发 ETF 大量覆盖时，窄门已关闭——这本身就是减仓信号。

**系统级下车信号（凌驾一切个股论点）**：≥2 家超大厂下修 capex 指引；capex 增速二阶导转负+债务融资占比恶化；scaling law 断裂或端侧推理里程碑达成；循环融资/私募信贷指标恶化。任一触发 → 全组合复核。

**元纪律（不为清单）**：不做空、不用杠杆、不懂不做；不因错过而降标准；证伪只标记不改写；一年合格论点不过几个——宁缺毋滥，窄门本来就窄。

## 五、回测纪律：三疫苗 + 多重检验（吸收 #01，2026-07-07 并入）

任何回测/统计规律进入决策讨论前，必须过四关：

1. **多重检验关**：随手测 1000 个乱编策略，纯运气就有约 50 个"看起来显著"。所以：(a) 必须有可陈述的经济学机理——回答"它凭什么赚钱"；(b) 样本外或前向窗口复验；(c) 参数敏感性检查（相邻参数结果断崖=过拟合信号）；(d) 如实记录本轮测试过的策略/参数总数——测得越多，显著性门槛越高。
2. **摩擦关**：滑点、手续费、成交失败必须计入；回测收益一律 **×0.7** 折扣后再讨论。
3. **前视关**：AST/规则级检查禁止使用"当时不可能知道的信息"（含用当日收盘价决策当日开盘）。
4. **前向关**（原有纪律，重申）：LLM 参与的验证只认"创建日快照+前向跟踪"，回看历史行情打分一律无效。
