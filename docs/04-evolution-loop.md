# 04 · 持续调查与进化范式（Evolution Loop v1）

> 目标：系统不靠人的意志力运转。调查是排程驱动的，进化是复盘驱动的，一切变化以 commit 留痕。
> 一句话范式：**四个嵌套闭环，快环喂慢环；git 是记忆，Routine 是心跳，复盘是选择压力。**

## 0. 设计原则

1. **进化的单位是 commit**——watchlist 更新、论点状态变化、信念沉淀、规则修订，全部是对本仓库的提交。系统今天和上个月有什么不同，`git log` 就是答案。
2. **快环喂慢环**——日环产生事件，周环把事件变成论点证据，季环把论点结果变成信念，年环把信念变成规则。任何一环断了，上层就在用过期认知决策。
3. **验证优先于收集**——每条进入系统的关键论断都要过对抗验证（R1 已证明其价值：首轮即拦下三条 A 股假订单叙事）。
4. **前向实验**——每个论点是一次前向实验（创建日快照+前向跟踪），命中率可统计，系统整体是否在变聪明可度量。

## 1. 四个闭环

### 环 1｜日环：采集与预警（自动，Routine 驱动）
```
/scan(tier1+active论点相关) → 事件入 journal(带半衰期) → 命中退出三通道? → 是→标红提请决策
```
- 触发：工作日定时 Routine（见 §3）。
- 产出：journal 当日条目、watchlist `last_checked`/`notes` 更新、需要决策的红色事项。

### 环 2｜周环：验证与论点维护（半自动）
```
本周事件汇总 → 关键论断补对抗验证 → 各 active 论点证据链增/删 → 拥挤度评分刷新 → /brief
```
- 产出：/brief 简报（含桶级暴露、时钟读数、待办）；论点"最后评审"日期滚动。
- 补研队列消化：每周从 `docs/research/` 的"未覆盖清单"取 1-2 项，跑一轮深度研究。

### 环 3｜季环：复盘与信念沉淀（人机共同）
```
关闭论点(/retro) → 信念条目入 journal/beliefs.md → 命中率/纪律健康度统计 → 注入未来同类评审
```
- 关键指标：论点命中率、平均持有期收益/回撤、"差点违反不为清单"次数、被证伪论点的共同死因。

### 环 4｜年环（或重大事件触发）：方法论进化
```
信念库聚类 → 哪些规则被反复验证/反复打脸 → 修订 docs/03-methodology.md、risk-rules.md、技能提示词 → commit
```
- 系统级证伪信号（risk-rules §6）命中时，本环立即触发，不等年度。
- **方法论修订必须引用信念条目作为证据**——规则的进化和论点一样要可证伪。

## 2. 外部方法论的吸收接口（持续调查"方式"本身）

## 4. 系统健康度（/brief 固定段落）

- 数据新鲜度：tier1 标的 `last_checked` 距今中位数（目标 ≤3 个交易日）
- 论点卫生：active 论点数（≤8）、超期未评审数（目标 0）
- 进化速率：本月信念条目数、方法论/规则修订 commit 数
- 纪律健康度：豁免次数、"差点违反"次数（趋势应向下）
