## 小白版重点（四句话）

1. **那个吓人的数字是张冠李戴**："Google 自由现金流从 733 亿跌到 82 亿"——733 亿是**去年真实发生的**（而且和前年持平，没崩）；82 亿是**一家研究机构对今年的预测**（Pivotal Research，CNBC 2026-02-06）。把预测当事实传播，恐慌就是这么造出来的。
2. **但压力是真的**：Google 明年 capex 指引三连跳到 1800-1900 亿美元、CFO 说 2027 还要"显著增加"；四大厂 2026 合计 capex 逼近 **7000 亿美元（+60%）**——"FCF 被吞噬"这个方向值得盯，只是还没发生。
3. **OpenAI 的输血在加码而非减速**：3 月底完成史上最大一轮融资（1220 亿美元承诺资本、8520 亿估值），但注意出资人名单——**Amazon 500 亿、Nvidia 300 亿**：供应商和合作方就是股东，这正是循环融资的教科书样本。
4. **AI 生产率的"弱环节"证据落地**：NBER 研究显示自主编码代理让代码提交 +180%，但实际软件发布只 +30%——写码不是瓶颈，评审/测试/发布的人力环节才是。**智能变成收入的转化链条比想象的长**，这是整链终极需求的结构性约束。

## 三、领先指标 L-c：循环融资敞口（基线值）

已确认的"谁在给谁输血"节点：

```
Nvidia ──$30B 入股──> OpenAI ──累计~$224亿合同──> CoreWeave <──至多$142亿(后扩至~$350亿)── Meta
   └──各$20亿入股+采购承诺──> Lumentum / Coherent（P0 轮已验证,SEC 8-K）
Amazon ──$50B(35B含条件)──> OpenAI
CoreWeave 收入积压 $556 亿（环比近翻倍），高度集中于 OpenAI/Meta 两个对手方
```

| 事实 | 票 |
|------|----|
| CoreWeave×OpenAI 扩约至多 $65 亿（2025-09-25），累计 ~$224 亿；×Meta 至多 $142 亿六年约（2025-09-30，2026-04 扩至合计 ~$350 亿）；积压 $556 亿、RPO >$500 亿 | 3-0 ×2 + 2-1 |
| 口径警示：合同额均为 **"up to"上限值**；积压集中度=输血链的单点风险 | — |

**L-c 触发线（v1）**：新增 vendor-financing 结构（供应商入股客户+采购承诺捆绑）单季 >$50B，或 CoreWeave 式中间商的对手方集中度进一步上升 → 预警。当前状态：**存量已可观，增速待 F1b 建立时间序列**。

## 四、领先指标 L-d：应用层变现进度（基线值）

| 事实 | 票 |
|------|----|
| NBER w35275（10 万+ GitHub 开发者+微软遥测）：自主代理 commits **+180%**，项目层 +50%，**实际发布仅 +30%**（另一口径：写码行数 17.3 倍，发布 1.3 倍）。流传说法口径纠正：不是"30% 的代码进入生产" | 3-0 ×3 |
| 机制："弱环节假说"——AI 与人类替代弹性仅 **0.25**（强互补）；评审/测试/发布/用户注意力才是瓶颈 | 3-0 |
| METR RCT（arXiv 2507.09089）：16 名资深开发者在自己维护的成熟仓库用 AI 反而**慢 19%**，自我感觉却快 20%；2026-02 后续队列收窄至 -4%——感知与现实的反差本身是叙事风险 | 3-0 |

**L-d 含义**：智能→收入的转化链比叙事长得多（工作论文+小样本，外推谨慎）。触发线（v1）：头部 AI 应用收入增速连续两季减速且 token 用量与收入背离扩大 → 预警。当前：**数据不足，待建立序列**。
