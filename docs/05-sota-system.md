# SOTA 投资系统总蓝图 v1.0（言出法随 · 完全体）

## 小白版：这台机器是什么？

**一句话：一台"自己找线索、自己查证、自己盯盘、自己反省，但把最终决定权留给你"的投资机器。**

把它想象成一家微型投资公司，但员工全是 AI：

```
你（老板）：定方向、做最终决策、出钱
    ↓ 说一句话
Fable 5（总监）：规划研究、把关质量、写结论   ←—— 每天自动开工
    ↓ 派活
Sonnet 5 军团（研究员）：上网查证、盯盘扫描      ~100人/任务
Opus 4.8（首席质检）：每条结论投反对票试图推翻   3票制
    ↓ 产出
git 仓库（公司档案室）：每个判断、每次错误全部留痕，可追溯
```

**为什么敢叫 SOTA？**因为每个部件都是从全球最好的实践里验证后抄来的，而且我们知道每一块是从哪抄的、为什么抄（下表）。

## 二、三条业务线（三个 git 分支，互不污染）

1. **主线（本分支）**：AI 算力链+Physical AI 论点驱动集中投资——窄门排序 v0.4（燃机>并网稀缺>变压器>InP 激光器>CoWoS 时限窄门…），每个判断带验证票数与证伪触发器
2. **quant 分支**：统计规律副线——七条铁律+回测协议 v1.1+Q1 跨市场供应链动量实验（规格已锁定，等门槛条件）
3. **commodities 分支**：商品线——铜为窄门首选，第一角色是给主线当"跨市场验证器"（101GW 燃机订单实证了 GEV 论点）

## 三、系统的心跳与进化（已在运转）

- **日环**：每个交易日 09:00（北京）自动扫描全部核心标的，红色事项置顶——已实战拦截 Bloom backlog 造假指控事件并按纪律降级处理
- **周环**：论点评审+拥挤度刷新；**季环**：复盘沉淀"信念条目"；**年环**：用信念修订方法论——**系统的每一次进化都是一个 commit，`git log` 就是它的成长史**
- **争议裁决日历**：不站队专家吵架，用事实裁决（当前挂牌：GEV 7/22 财报、CPO Q3 出货、Bloom 下季 10-Q、宇树挂牌首日）

## 四、与市面所有方案的三个差异点

1. **对抗验证是一等公民**：每条关键数字 3 票制（1 强怀疑者+2 独立票）——市面框架（TradingAgents 等 91k 星项目）都没有这道闸门，我们靠它拦下三花假订单、拓普假定点、Medallion 假数字、绿的假产能
2. **证伪先于持有**：写不出"我错了的情形"的判断不许进系统；每个 watchlist 条目自带退出触发器
3. **AI 永不碰扳机**：研究→建议→由你决策；算法只做纸面前向实验，真金白银的每一步都过人手
