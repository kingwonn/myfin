# 定价五步法 v1.0 —— 任何 T1 标的转 active 前的强制流程

> 首个实例：P1/P1b GEV 裁决（docs/research/2026-07-12-p1-gev-pricing.md）。信念 B17 的操作化。
> 原则：研究回答"是不是真的"，本法回答"值不值得买"——五步走完之前，任何论点不得转 active。

## 小白版：这是什么

给"好公司"量体温的五个步骤，防止我们在事实全对的情况下买在错误的价格上。每一步都是算术，不是感觉。

## 五步流程

### 第 1 步：洗噪音
- 找出污染估值倍数的一次性项目（并购重估收益、递延税释放、资产处置）。
- **产出**：干净的 trailing 与 forward 利润口径。
- GEV 实例：trailing P/E 32 是假象（$4.5B Prolec 重估收益）；GAAP forward EPS $30.64 是假象（递延税垫高）——干净口径 forward P/E ≈70x。

### 第 2 步：今日倍数
- EV = 市值 − 净现金（净现金用 10-Q 实测，不许假设超过一个季度）。
- 算：EV/EBITDA（当年指引中点 + 中期目标年）、P/FCF（注意预付款美化）、调整后 forward P/E。
- **产出**：一张"今天为未来哪一年付钱"的表。

### 第 3 步：隐含预期反推
- 问题固定为："当前 EV 在成熟期倍数假设（[假设区间] 13-18x EV/EBITDA，可比数据到位后替换）下，需要多大的终局利润？相当于公司自己中期目标的几倍？按合理增速要长到哪一年？"
- **产出**："市场已经买到了 XX 年"的一句话结论。

### 第 4 步：脆弱性检查
- 中期目标的最脆弱假设是什么（利润率？某个亏损分部的复苏？）；FCF 质量（预付款/营运资金驱动的部分要打折）；情绪面（卖方买卖评级分布 + 拥挤度评分并读）。
- **产出**：下修情景下倍数恶化到多少。

### 第 5 步：闸门
- 双通道，任一满足才可评审转 active：
  - **价格路径**：隐含 EV/EBITDA(中期目标年) ≤ 20x 对应的股价；
  - **基本面路径**：中期利润目标上修至使当前价对应 ≤20x。
- 闸门数字写进论点文件，修改须书面记 journal。

## 口径陷阱清单（每次反推前过一遍，血泪实证）

| 陷阱 | 实证案例 | 防法 |
|------|---------|------|
| 实际 vs 预测混用 | "Alphabet FCF 733→82 亿"：733 亿是实际、82 亿是分析师预测（F1 拆穿） | 每个数标注 [已报告]/[指引]/[分析师预期] |
| GAAP vs 调整后 | GEV FY26 EPS：GAAP $30.64 vs 调整后 $15（差 2 倍，P1b） | 反推一律调整后；两套口径都写出来 |
| 一次性收益污染 | GEV trailing P/E 32（含 $4.5B 重估收益） | 第 1 步强制洗噪音 |
| "up to"上限口径 | CoreWeave 合同额全是 up-to（F1） | 上限值不当基准值用 |
| 预付款美化 FCF | GEV Q1 FCF $4.8B 主要靠燃机预付款 | FCF 质量注记强制 |
| 有机 vs 并表 | GEV 2028 目标 $52B 有机 vs $56B 含 Prolec | 增长率计算先统一口径 |
| 名义值 ≠ 风险资本 | Burry 11 亿"空头"是期权名义值（E1b） | 衍生品口径单独标注 |
