---
description: 扫描 watchlist 中标的的最新关键动态，输出变化摘要
---

遍历 `watchlist/*.yaml` 中所有 `tier: 1` 与 `tier: 2` 的标的（若用户在参数中指定了链条或标的，则只扫描指定范围）：

1. 对每个标的，用 WebSearch 检索最近的关键动态，聚焦四类信号：
   - 产能/供给变化（扩产、良率、交付周期）
   - 订单/客户变化（大客户中标、份额变化、砍单）
   - 技术路线变化（可能颠覆其卡位的新路线进展）
   - 估值极端化（暴涨暴跌、重要股东减持）
   - **物理证据**（扩产/招工/环评/上游设备订单/供应商公告——物理数据领先财报 2-4 个季度，是低拥挤度窗口）
2. 与该标的 YAML 中的 `moat` 和 `risk` 字段对照：新信息是否强化/削弱护城河？对每个 active 论点逐条核对**退出三通道**（证伪/破位/兑现）。
3. 事件带半衰期属性记录（FinMem 式）：盘面异动=天级、业绩指引=季级、商业模式/产能格局变化=年级；/brief 取用时按衰减后权重排序。
4. 数量多时用 Workflow 并行扫描，每个标的一个 agent。

输出：
- 按"需要立即关注 / 值得记录 / 无变化"三档汇总，中文。
- 有实质变化的标的：更新其 YAML 的 `last_checked` 与 `notes` 字段。
- 若触发了某个 thesis 的证伪条件或触发器：明确指出，并提示用户评审对应 thesis 文件。
